Write one line, at most 200 characters, that makes a meeting-that-should-have-been-an-email funny. A judge model reads entries in pairs and keeps the funnier line. Free to enter.

The program writes a single original one-liner to `/output/entry.txt`:

> The meeting's only decision was to book a follow-up meeting to decide if the first meeting could have been an email.

## Run it

```sh
python3 main.py
```
